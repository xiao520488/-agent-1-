**下面是agent loop**

↓

↓
↓

↓

**下面是三个坑**
第一个坑：要给循环加一个上限，否则可能会造成无用的消耗
第二个坑：要在system提前把规矩讲清楚，比如提前跟他说我是WINDOWS系统，这样他就不会先去其他的地方找，避免无用的重复
